# Package index

## All functions

- [`annotate_nearby_features()`](https://cnluzon.github.io/bedscout/reference/annotate_nearby_features.md)
  : Annotates a GRanges object with nearby features in another GRanges
  object
- [`annotate_nearest_features()`](https://cnluzon.github.io/bedscout/reference/annotate_nearest_features.md)
  : Annotate the closest feature
- [`annotate_overlapping_features()`](https://cnluzon.github.io/bedscout/reference/annotate_overlapping_features.md)
  : Annotates a GRanges object with overlapping features in another
  GRanges object
- [`calculate_venn_intersections()`](https://cnluzon.github.io/bedscout/reference/calculate_venn_intersections.md)
  : Calculates all intersections in a list of GRanges object for a venn
  diagram of an arbitrary number of elements.
- [`combinations_enrichment()`](https://cnluzon.github.io/bedscout/reference/combinations_enrichment.md)
  : Calculate enrichment combinations of different elements within a
  list
- [`combinations_score()`](https://cnluzon.github.io/bedscout/reference/combinations_score.md)
  : Apply a given score function to all pairs in a list of GRanges
  objects
- [`.intersect_subset()`](https://cnluzon.github.io/bedscout/reference/dot-intersect_subset.md)
  : Intersection of a list of GRanges filtering by index. The use of
  this is to be able to map by powerset
- [`.key_value_string()`](https://cnluzon.github.io/bedscout/reference/dot-key_value_string.md)
  : Make a string out of a named list.
- [`.limited_size_caption_line()`](https://cnluzon.github.io/bedscout/reference/dot-limited_size_caption_line.md)
  : Make a string out of a named list. Split into lines if too wide.
- [`.make_venn_names()`](https://cnluzon.github.io/bedscout/reference/dot-make_venn_names.md)
  : Make names for intersections according to index list
- [`.package_caption()`](https://cnluzon.github.io/bedscout/reference/dot-package_caption.md)
  : Make a string to put as caption in verbose mode. Includes system
  date.
- [`.powerset()`](https://cnluzon.github.io/bedscout/reference/dot-powerset.md)
  : Calculates all possible subsets of a list of elements
- [`fc_enrichment()`](https://cnluzon.github.io/bedscout/reference/fc_enrichment.md)
  : Calculate fold change enrichment of a GRanges object's overlap with
  another GRanges object based on genome size.
- [`fit_euler()`](https://cnluzon.github.io/bedscout/reference/fit_euler.md)
  : Find a fit for a set of intersections in the form of an euler
  object.
- [`gr_universe()`](https://cnluzon.github.io/bedscout/reference/gr_universe.md)
  : GRanges universe for a set of conditions and replicates
- [`grlist_intersect()`](https://cnluzon.github.io/bedscout/reference/grlist_intersect.md)
  : Find the intersection of a list of GRanges objects.
- [`grlist_intersect_size()`](https://cnluzon.github.io/bedscout/reference/grlist_intersect_size.md)
  : Calculate the size of the intersection of a list of GRanges objects.
- [`import_named_bed_into_list()`](https://cnluzon.github.io/bedscout/reference/import_named_bed_into_list.md)
  : Make a named bed into a list of GRanges objects to be used with
  pairwise functions, mostly.
- [`impute_feature()`](https://cnluzon.github.io/bedscout/reference/impute_feature.md)
  : Annotate each locus in a GRanges with the best overlap in another
  feature GRanges. Best overlap is calculated as jaccard index:
- [`jaccard_index()`](https://cnluzon.github.io/bedscout/reference/jaccard_index.md)
  : Calculate jaccard index between two GenomicRanges objects.
- [`loci_consensus()`](https://cnluzon.github.io/bedscout/reference/loci_consensus.md)
  : Find a consensus set of loci across a set of GRanges objects.
- [`loci_overlap()`](https://cnluzon.github.io/bedscout/reference/loci_overlap.md)
  : Calculate the number of loci that overlap between two GRanges
  objects (ignoring length).
- [`pairwise_enrichment()`](https://cnluzon.github.io/bedscout/reference/pairwise_enrichment.md)
  : Calculate pairwise enrichment matrix between two lists of GRanges
  objects
- [`pairwise_score()`](https://cnluzon.github.io/bedscout/reference/pairwise_score.md)
  : Apply a given score function to all pairwise combinations of two
  named GRanges lists
- [`peaks_universe()`](https://cnluzon.github.io/bedscout/reference/peaks_universe.md)
  : Peaks universe for a set of conditions and replicates
- [`plot_combinations_score()`](https://cnluzon.github.io/bedscout/reference/plot_combinations_score.md)
  : Plot triangular pairwise enrichment heatmap for a single GRanges
  list
- [`plot_euler()`](https://cnluzon.github.io/bedscout/reference/plot_euler.md)
  : Plot a Euler diagram with intersections between GRanges objects
- [`plot_pairwise_score()`](https://cnluzon.github.io/bedscout/reference/plot_pairwise_score.md)
  : Plot pairwise enrichment heatmap
- [`total_bp_overlap()`](https://cnluzon.github.io/bedscout/reference/total_bp_overlap.md)
  : Total overlapping base pairs between two GRanges objects.
